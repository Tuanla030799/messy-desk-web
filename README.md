# Creative Playground Blog

A personal creative blog/playground website built with Nuxt 4 and Vue 3.

It is designed as a personal space for writing, notes, project showcases, gallery posts, UI experiments, and tiny playground pages.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Content

Most demo content lives in `src/data/content.ts`, so you can replace the sample posts, notes, projects, gallery items, and experiments without touching page logic.
